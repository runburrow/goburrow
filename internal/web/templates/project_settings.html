Report API

For anything without a Sentry SDK: game servers, shell scripts, cron jobs. POST JSON with the project key in the X-Burrow-Key header.

{{.Data.ReportURL}}
{{$p.PublicKey}}

Example

curl {{.Data.ReportURL}} \
  -H "X-Burrow-Key: {{$p.PublicKey}}" \
  -H "Content-Type: application/json" \
  -d '{"message": "Payment failed for order 1182", "level": "error",
       "stack": "...", "environment": "production", "tags": {"region": "eu"}}'

Only message is required. A stack in Luau, Lua, Python or JavaScript form becomes frames. Send up to 100 reports at once as a JSON array. The key is the same one in the DSN, so rotating it changes both.
